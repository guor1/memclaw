## 命名约定

- **design/** 保留数字前缀（有阅读顺序）；其余目录用语义命名，**不加全局编号**
  （历史上全局编号导致过撞号：两个 `07-`）。
- 专题文档统一 `<阶段项>-<主题>.md`，如 `P1-3-偏好supersede测试用例.md`。
- 内部链接用相对路径：跨目录 `../plan/xxx.md`，引用源码 `../../crates/...`。
