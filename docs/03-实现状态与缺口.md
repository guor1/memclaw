## 1. 总览

M1–M6 主体里程碑已落地，核心闭环可跑：对话 / 持久化（重启不失忆） / 记忆检索（Lane1 词法） /
防卡死全套 / 工具+审批 / cron 主动性 / CLI 命令树。跨里程碑不变量保持：
`oc-core` 无 IO（已 grep 验证）、依赖单向无环、记忆/dreaming/proactive 失败不阻塞主会话、prompt 组装确定性。

下表列出**已确认落地**与**尚未落地**的项。缺口按"实质功能" > "收口项"排序。

### 3.3 语义偏差（已实现但与设计细节不完全一致）

- **cron day-of-month / day-of-week 语义**：标准 cron 两者都非 `*` 时取 **OR**；当前实现取 **AND**
  （见 `oc-core::proactive::cron`，个人助手场景多数只用其一，已注明）。
